# 体检报告整理

对应 EX02。打开「体检报告整理」，上传单页 JPEG 或 PNG。识别需要个人档案的 AI 总授权，以及支持图片输入和结构化输出的模型。原图用于页面核对，服务会缩小并重新编码后发送给模型。

预览包括报告日期，以及指标名称、结果、单位、原报告参考范围、页面位置和原文摘录。用户可逐项纠正、移除误识别的条目并补填日期。只有点击确认保存才会写入数据库。原图不会保存在平台业务记录中。页面位置和摘录随核对后的结果保存。

历史列表、详情和删除使用本人 JWT。已保存的报告纳入个人数据导出及账号删除。整理功能仅转录原报告项目。

已有库执行 `database/migrations/028_checkup_reports.sql`。表以用户编号逻辑关联。接口使用 `/api/checkups`，其中 `POST /preview` 接收 multipart 字段 `photo`。
