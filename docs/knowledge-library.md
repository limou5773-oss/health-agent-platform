# 健康知识库

对应 US17。登录用户可按睡眠、运动、饮食与饮水、情绪与生活、综合分类浏览，按关键词检索标题和正文，并收藏已发布的资料。收藏按账号保存，重复收藏保持一条记录。下架资料从浏览、收藏列表和 Agent 检索中隐藏。

默认相关度排序依次为标题完全匹配、标题包含关键词、正文包含关键词；同级按更新时间和编号倒序。选择「更新时间」时直接按更新时间和编号倒序。无关键词时同样按更新时间排序。列表最多返回 100 条。

管理员在「管理后台 → 知识资料」维护分类及发布状态。升级后旧资料默认归入综合，内置睡眠统计口径归入睡眠。睡眠报告保留生成时的引用摘要，可打开仍发布的库内资料。下架后库内详情不可访问，已有报告仍保留当时的标题、来源和可用的原始链接。

- `GET /api/knowledge` 支持 `query`、`category`、`sort`（`RELEVANCE` 或 `RECENT`）、`favoritesOnly`，返回 `category` 和本人收藏状态 `favorite`。
- `GET /api/knowledge/{id}` 获取已发布资料。
- `PUT /api/knowledge/{id}/favorite` 收藏，`DELETE /api/knowledge/{id}/favorite` 取消收藏。

已有数据库执行 `database/migrations/020_knowledge_library.sql`，新库使用最新建表脚本。收藏使用用户编号和资料编号的联合主键及逻辑关联。
