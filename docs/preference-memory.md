# 用户偏好记忆

对应 AG09。进入「个人档案 → 长期偏好记忆」逐项保存、查看、修改或删除长期目标、运动偏好、作息和提醒时段。每类保存一项文字，最多 500 字符。保存按钮是用户确认入口，聊天内容不会自动写入。提醒时段供计划草稿安排参考，提醒调度由后续功能实现。

## 接口

- `GET /api/profile/preferences` 返回当前登录用户已保存的 `[{kind, content}]`。
- `PUT /api/profile/preferences/{kind}` 接收 `{content}`，返回保存后的条目。同类再次保存会覆盖该条。
- `DELETE /api/profile/preferences/{kind}` 删除该类并返回 204，删除不存在的类别也返回 204。

类别为 `GOAL`、`EXERCISE`、`ROUTINE`、`REMINDER`。身份由 JWT 绑定。数据库按 `user_id` 与档案逻辑关联，`(user_id, kind)` 为主键。

## Agent 使用与升级

外部模型授权开启时，运行中的计划任务在每轮决策及结构化输出前从 Java 读取当前已保存偏好。偏好原文不作为独立消息保存到任务检查点。模型生成的历史草稿或正式计划可能已引用偏好，编辑或删除记忆后不会回写这些历史产物。已发给外部模型的信息无法从本地撤回。

旧档案的目标和自由文本偏好仍保存在原字段，沿用原档案工具的授权规则。长期记忆只包含用户通过新入口保存的内容。健康指标继续由对应工具提供。
