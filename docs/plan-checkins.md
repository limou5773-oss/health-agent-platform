# 打卡日历与连续完成天数

对应 US14。在「我的计划」选择计划后，可按月查看打卡日历，点击有任务的日期筛选当天安排。完成率、当前连续天数和最长连续天数在计划详情展示。未完成原因可在周期复盘填写，计划任务列表同步显示。

- 完成率按档案时区截至当天统计。分母为当前有效且安排日期不晚于当天的任务数，分子为其中已打卡的任务数。没有应完成任务时显示「暂无到期任务」。
- 某日有有效任务且全部打卡才算完成一天。最长连续天数按连续自然日统计，无任务日和未完成日中断连续。当前连续天数截至当天或昨天，已经结束的周期截至计划结束日期。尚未完成的当天保留截至昨天的连续天数。
- 进行中的计划可以补打卡。提交任务原安排日期，实际操作时间由服务端记录。未到日期时不能新增打卡。同一任务及日期重复提交继续返回原打卡。

`GET /api/plans/{id}` 返回 `progress`（`today`、`dueItems`、`completedItems`、`completionRate`、`currentStreak`、`longestStreak`），项目包含 `missedReason`。原打卡及撤销接口继续使用。无需数据库迁移。
