# 周期复盘

对应 AG10。在「我的计划」选择计划，展开「周期复盘」，填写已结束的 1 至 31 天日期范围并查询。是否结束按档案时区判定。查询实时读取打卡及健康记录，补录数据后可以重新查看。

- 完成率为所选周期内已打卡任务数除以仍有效的任务数。计划修订替换的任务不计入。无任务时显示「无任务」。
- 未打卡任务可单独填写未完成原因，留空保存可清除。完成打卡时清除该任务此前填写的原因。
- 支持选择睡眠、步数、运动时长、饮食热量、饮水量或体重，比较所选周期及其前一个连续等长周期。沿用个人基线的每日统计和来源规则，显示各期均值和覆盖。两期各有至少 70% 的有效天数时才显示日均差值。差值描述观测结果。
- 可为未打卡任务选择今天或之后的日期，把改期建议和已保存原因带入现有修订编辑器。建议在用户保存前仅作为编辑内容。保存后走原草稿比较及确认流程，保留已打卡任务。已有修订草稿时先处理该草稿。

## 接口和升级

- `GET /api/plans/{id}/review` 使用 JWT 和计划归属校验。查询字段为 `startDate`、`endDate`、`metric`，可选 `sourceName`。返回 `planVersion`、档案时区的 `today`、`scheduled`、`completed`、可空的 `completionRate`、`missed` 和 `comparison`。
- `PUT /api/plan-items/{id}/missed-reason` 接收 `{reason}`，最多 500 字符，成功返回 204。任务必须属于当前用户、尚未被修订替换、日期已过且未打卡。
