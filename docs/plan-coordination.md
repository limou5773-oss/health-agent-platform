# 多目标协调

对应 EX04。在「我的计划」打开一份进行中的计划，展开「多目标协调」，选择其他优先保留的进行中计划和每日可用时段。计划沿用现有的计划创建、目标和打卡流程。

当前计划与所选优先计划之间，同日同名视为重复，同一分钟视为时间冲突。未来的重复任务可从当前计划草稿移除，且至少保留一个任务。其余时间冲突建议改到当天可用时段内最早的空闲分钟，已有提醒随任务改到该时刻。已打卡、已到时间或当天无可用时间的任务保留并显示原因。重新检查可获得最新安排。

预览可带入修订编辑器，用户先保存、核对差异，再确认应用。沿用现有版本校验和已打卡任务保护。优先计划的安排在预览时读取，草稿只涉及当前计划。

`POST /api/plans/{id}/coordination/preview` 接收 `priorityPlanIds`、`availableFrom` 和 `availableUntil`，范围为同一天，开始含、结束不含，时间精确到分钟。该接口使用本人 JWT，并复用现有表结构。
