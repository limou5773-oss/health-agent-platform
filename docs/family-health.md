# 家庭健康空间

对应 EX05。在「家庭健康空间」输入已注册成员的用户名，勾选允许查看的指标、具体报告版本，并设置 1 至 365 天有效期。成员使用自己的账号接受邀请后，可查看授权指标的汇总统计和指定报告。报告本身可能包含多项指标或日记背景，请核对正文后再授权。

指标访问范围为睡眠、步数、运动、饮食、饮水、体重和心率的已勾选项。家庭空间使用只读汇总和报告详情，不提供原始明细、资料写入或 Agent 会话访问。报告失效后不能再读取。双方均可移除授权。再次邀请同一成员会替换原邀请，新邀请仍须接受。

所有接口使用本人 JWT。每次读取重新检查接受状态、双方账号状态、授权内容和有效期。有效期从发出邀请起算。个人数据导出包括与本人相关的邀请和授权，删除账号会清理双方关联记录。

已有库执行 `database/migrations/029_family_health.sql`，新库使用最新 schema。授权表通过用户编号逻辑关联。
