# 后台 Agent 任务管理

对应 AD04。在「管理后台 → 任务运行」选择一条任务查看步骤、状态、记录时间、产物编号、已确认的草稿版本与反馈。后台使用预定义步骤名称和固定调用说明，未知步骤归为其他执行步骤。列表只显示通用失败提示，原任务错误详情由任务所属用户查看。

用户可以在已完成的任务详情中选择「有帮助」或「没有帮助」，可更新选择。反馈随任务保存。关联健康数据变化使任务结果失效时，反馈同时清除。确认时间从本次升级后开始记录，旧任务仍可查看已保存的草稿版本。

- `GET /api/admin/tasks/{id}` 返回脱敏任务详情和步骤。使用现有管理员权限。计划确认仍走原任务所属用户的接口。
- `PUT /api/agent/tasks/{id}/feedback` 接收 `{feedback}`，取值为 `HELPFUL` 或 `NOT_HELPFUL`。仅任务所属用户可对已完成任务提交。

已有库执行 `database/migrations/019_task_audit.sql`，新库使用最新 `database/schema.sql`。
