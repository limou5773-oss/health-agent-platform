# 专项健康报告与阶段对比

对应 US18。进入「健康报告」，选择「专项报告」或「阶段对比」。支持睡眠时长、步数、运动时长、饮食热量、饮水量、体重和心率。每期为已结束的 1 至 366 天，按档案时区判断是否结束。对照周期早于报告周期，两期使用同一来源筛选。

报告保存生成时间、指标、日期范围、各期来源摘要、有效天数、缺失日期、日均值和计划完成情况。统计沿用个人基线口径。任一期覆盖不足 70% 时只保存各期描述统计；两期达标时差值为报告周期日均值减对照周期日均值。仅当全部选定周期均无有效指标记录时拒绝生成。来源冲突沿用现有错误提示。本地统计无需外部模型，来源来自实际记录。

心率显示全部实际采样的均值和条数。两期达标时比较采样均值。报告可按周期与来源打开健康时间线。

按用户、报告类型、指标和完整日期范围递增版本。报告在同一事务中保存。与综合报告一致，记录修改、删除或撤销打卡按日期影响报告；阶段对比任一期相交即可标记失效并清除快照，日期间隙不会触发失效。

`POST /api/reports/focused` 接收 `metric`、`startDate`、`endDate` 及可选 `sourceName`。提交完整的 `comparisonStartDate` 和 `comparisonEndDate` 创建阶段对比。沿用 JWT、报告详情和历史列表。已有库执行 `database/migrations/021_focused_health_reports.sql`。
