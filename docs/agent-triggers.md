# 主动任务触发

对应 AG11。进入「健康助手 → 主动任务设置与记录」，分别开启每周睡眠复盘或睡眠导入后分析，设置来源和是否发送任务创建站内消息。两项默认关闭。创建和执行任务均沿用档案的外部 AI 授权。

- 每周睡眠复盘按档案时区选择最近一个完整自然周，星期一至星期日，使用现有睡眠报告任务。后台每分钟检查，启用后可在本周内触发上一周复盘。后端停机跨过多个周期时，仅处理最近一个完整周。
- 睡眠导入确认实际新增记录时，使用设置中的来源匹配此次新增记录。以匹配记录的最新睡眠归属日期为结束日，含当天向前取设定的 1 至 31 天，创建睡眠分析任务。来源留空时取此次新增记录的最新归属日期，并按现有全部来源规则分析。仅重复记录、预览及步数导入不触发此睡眠任务。
- 用户、触发类型和日期范围组成去重键，另以周结束日期或导入批次编号记录事件。触发记录与任务同一事务写入，提交后才交给现有 Agent 执行。删除任务后保留去重记录。关闭开关停止后续创建，已创建任务可在任务中心处理。
- 可选站内消息在任务创建时发送。成功的睡眠报告也可按消息中心原有报告设置提醒。任务状态和结果沿用健康助手，来源冲突、待补充和失败均可在任务详情查看。

## 接口和升级

- `GET /api/agent/triggers/settings` 读取设置，`PUT /api/agent/triggers/settings` 保存 `weeklyEnabled`、`importEnabled`、`importDays`、`sourceName`、`notifyInApp`。
- `GET /api/agent/triggers/runs` 返回最近 50 条本人记录，包含触发类型、事件编号、周期、分析来源、创建时间和现有任务状态。

已有库执行 `database/migrations/014_agent_triggers.sql`，新库使用最新 `database/schema.sql`。接口沿用 JWT 和逻辑关联。
