# 计划前后对比

对应 EX03。在「我的计划」打开指定计划，展开「计划前后对比」，选择指标及可选来源。支持睡眠、步数、运动、饮食、饮水、体重和心率。

按当前生效版本的起止日期计算计划天数。计划前窗口截至开始日前一天，计划后窗口从结束日后一天开始，两期均与计划等长。以档案时区判定计划后窗口是否结束。完成度是计划周期内已打卡项目数除以当前有效项目数。日期和完成度随生效计划及打卡记录更新。

沿用个人基线的指标口径和来源冲突规则。每期展示均值、覆盖和缺失日期，两期均达到 70% 覆盖率才显示差值。均值与完成度并列呈现，仅用于观察。样本入口打开指定周期和来源的时间线。运动样本入口按开始日期定位，统计使用与该周期重叠的运动时段。

`GET /api/plans/{id}/outcome?metric=SLEEP&sourceName=...` 使用当前用户 JWT。计划后窗口尚未结束时返回 409 和可查询的时间条件。本功能复用现有表结构。
