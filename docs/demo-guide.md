# 演示与人工验收说明

对应需求第 10.1 节的统计固定样例、第 11.2 节的三条演示流程和第 11.3 节的交付物。下文的数值是样例预期值，实测结果由验收人记录。

## 准备

1. 按[本地运行说明](../README.md#本地运行)建立项目库并启动三端。首次演示使用新注册的演示账号，档案时区设为 `Asia/Shanghai`。睡眠和步数上传时选择同一文件时区。
2. 样例使用合成记录，来源统一以 `Demo` 开头。下载原始 CSV 后，在对应页面选择通用 CSV，核对预览后确认。避免与个人数据混用。
3. 执行 Agent 流程前配置可用的模型连接，并在「个人档案」开启 AI 总授权和本次使用的指标授权。仅演示导入、看板和综合周报时，无需开启 AI 授权。

## 固定样例与核对值

| 文件 | 上传入口或用途 | 核对值 |
| --- | --- | --- |
| [sleep-week.csv](samples/sleep-week.csv) | 睡眠记录 → 可穿戴设备数据导入 | 醒来日期 2026-11-02 至 2026-11-08，7 天各 1 条，日时长依次为 6、7、8、6.5、7.5、7、7 小时，合计 49 小时，日均 7 小时 |
| [sleep-quality.csv](samples/sleep-quality.csv) | 睡眠记录 → 独立核对错误和去重 | 5 行中可新增 2 条、批内重复 1 条、无效 2 条。2026-11-12 至 2026-11-14 共 13 小时，覆盖 2/3 天，日均 6.5 小时。11 月 13 日缺失 |
| [steps-week.csv](samples/steps-week.csv) | 运动管理 → 导入步数 | 主周期有 4 个累计快照，合计 24000 步，有效日均 6000 步，覆盖 4/7 天 |
| [weight-week.csv](samples/weight-week.csv) | 体重管理 → CSV 导入 | 3 天各 1 次测量，日代表值均值 70.0 kg，覆盖 3/7 天 |
| [heart-rate-week.csv](samples/heart-rate-week.csv) | 心率采样 → CSV 导入 | 3 天共 4 次测量，采样均值 70 次/分，覆盖 3/7 天 |

首次导入 `sleep-week.csv` 对应 AC02。AC03 使用独立日期范围的 `sleep-quality.csv`，在确认前刷新记录列表，核对正式记录数量，再检查预览中的问题行和新增数。完成 AC02 后再次预览同一文件，对应 AC04，预期 7 条均为重复、可新增 0 条。查看 `Demo Sleep` 的 2026-11-02 至 2026-11-08 统计，核对总时长和有效天数保持一致。

## 演示一：睡眠改善

1. 导入睡眠周样例。在「综合健康看板」选 2026-11-02 至 2026-11-08，睡眠来源选 `Demo Sleep`，核对覆盖和平均时长。11 月 2 日 23:30 开始的记录归到 11 月 3 日。
2. 在「健康助手」选择「睡眠分析」，使用同一范围和来源。可输入“查询所选周期的睡眠覆盖和日均时长，说明统计来自哪里”。记录任务编号、工具执行情况，并将结果与看板的 7 天及 7 小时核对。
3. 使用相同分析范围发起「制定计划」，单独填写实际执行周期。若要当天演示打卡，执行起始日选演示当天。检查和修改草稿，确认后在「我的计划」打开正式计划，完成一项当天任务。确认前后均可查看计划列表。
4. 待执行周期结束后，在计划详情选择「周期复盘」，核对计划任务数、打卡数和指标覆盖。填写未完成原因或查看改期建议，按需将建议带入修订草稿。

## 演示二：运动管理

1. 在「运动管理」导入步数样例，使用主周期与 `Demo Steps` 核对有效日均和缺失日期。设置本人步数目标，在「个人档案」填写可用时间和运动偏好。
2. 在「健康助手」选「制定运动计划」，分析日期使用 2026-11-02 至 2026-11-08，步数来源选 `Demo Steps`，另填计划执行周期。核对任务使用的步数来源、4/7 天覆盖和待确认草稿。此流程可用只开启 AI 总授权和活动授权的演示账号验证。
3. 确认计划后可在「运动管理」录入一条实际安排演示的运动，按页面条件选择对应的当日计划项目，再显式打卡。查看「我的计划」的完成情况，积累新记录后用「周期复盘」或修订草稿调整后续任务。

## 演示三：综合周报

1. 导入主周期的睡眠、步数、体重和心率样例。若需要演示日记授权，可在同一周期手工新增一条标明“合成演示”的日记，按需开启档案日记授权、单条授权，并勾选 Agent 任务的日记选项。
2. 在「健康报告」选择「综合周报」，结束日期设为 2026-11-08。核对七项指标各自的来源和覆盖，沿报告来源链接打开同周期的时间线。未录入的指标应当显示缺失。重新生成相同周期可切换版本。
3. 需要展示有日记背景的分析时，另发起「综合分析」，在任务步骤中核对模型是否读取了获授权的日记。综合周报使用 Java 统计。需要制定下一周期计划时，可在「健康助手」发起「制定计划」，查看并确认生成的草稿。
