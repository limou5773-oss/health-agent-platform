# AI 数据授权

在「个人档案」设置外部模型总授权，以及睡眠、步数与运动、体重、心率、日记五类数据权限。睡眠分析、睡眠报告、计划生成和主动睡眠任务需要睡眠授权。综合分析至少需要一个已授权的健康指标，仅返回已授权指标的统计。档案体重也受体重授权约束。日记同时需要档案授权、单次任务勾选和逐条授权。

撤回任一授权后，后端拒绝旧授权下任务的继续、重试、工具查询和结果保存。重新授权后可创建新任务。已保存结果可查看或主动删除，源记录删除仍沿用关联结果及检查点清理流程。已发送给外部模型的数据无法通过平台撤回。

撤销打卡会清除覆盖该日期且读取过打卡汇总的 Agent 任务、追问和检查点中的内容，并使相关报告失效。打卡汇总的读取和成功步骤在同一事务记录，以便定位受影响的任务。

已有数据库先应用前序迁移，再执行 `database/migrations/026_ai_data_permissions.sql`。迁移保留原总授权，睡眠和日记使用原有规则，活动、体重和心率需单独开启。升级前尚未完成的 AI 任务如需继续调用模型，须重新创建。已生成的计划草稿仍可在本地编辑并确认。新账号总授权默认关闭。

`GET /api/profile` 返回 `aiConsent`、`aiSleep`、`aiActivity`、`aiWeight`、`aiHeartRate` 和 `aiDiary`。通过 `PUT /api/profile` 保存。旧客户端省略各数据权限时保留原设置。授权版本由服务端维护。
