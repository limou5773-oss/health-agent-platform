# 苹果健康睡眠文件导入

本项对应开发方案第6.4节及需求US03、US04、US07、NF03，在现有睡眠流程上接入苹果健康导出文件。计划顺序不变，后续才扩展运动及其他指标。

## 实现范围

- XML / ZIP上传、流式读取、来源与时区转换、错误项和未支持项预览。
- 支持未分期、核心、深睡和REM睡眠；保留原始阶段及偏移时间。
- 同来源连续或重叠记录形成一个日期归属区间，清醒和在床记录只用于识别该区间，不增加睡眠时长；不使用额外的时间间隔阈值连接缺失记录。
- 秒级区间合并与时长换算，复用重复处理、确认入库、看板、任务统计和来源选择。
- 批次记录标明CSV或苹果健康格式，以及有效、无效、跳过和不支持的数量。
- 受现有本地时间存储约定限制，同来源、同睡眠日期的真实睡眠覆盖范围若跨越夏令时或UTC偏移切换，相关条目显示为不支持，提示使用UTC档案时区重新导入；其余有效记录仍可确认入库。

## 数据库升级

新库使用最新版 database/schema.sql。已有库通过本次002迁移补齐批次格式、质量计数、分段归属日期和小数分钟字段；仍保留旧外键的库另按001迁移移除外键。数据继续使用业务编号逻辑关联。

## 验证分工

开发侧只做编译构建和代码核对。没有真实脱敏导出样本时，将状态记录为“解析代码已编写，真实样本待验证”，不声称实际设备接入或功能测试通过。功能测试及样本验证由用户负责，不编写自动化回归测试。

文件大小、展开量及记录数量限制直接对应NF03；关闭外部实体、不解压文件路径属于本次文件输入边界的必要处理。除此之外不加入通用防御层、静默回退或自动重试。

## 官方依据

- [苹果健康导出说明](https://support.apple.com/guide/iphone/share-your-health-data-iph5ede58c3d/ios)：健康与健身数据可以导出为XML。
- [HealthKit睡眠分类](https://developer.apple.com/documentation/healthkit/hkcategoryvaluesleepanalysis)：睡眠类别区分在床、清醒、未分期及具体睡眠阶段；阶段记录可能重叠，统计采用实际睡眠区间。
