# Agent 分析追问

对应 AG01。在已完成的睡眠分析、综合分析、睡眠周报或已确认的 Agent 计划详情输入追问。睡眠周报也可通过报告详情的「查看生成任务并追问」进入。每轮生成独立的只读分析任务，可查看进度、统计、反馈和前一轮入口。

追问沿用原分析日期、来源筛选及日记选项，并重新查询当前记录。健康统计以本轮查询为准。上一轮问答、睡眠周报正文或确认时的计划标题、依据和安排摘要用于理解上下文。运动计划的追问只读取步数和运动统计。需要更换日期或来源时新建分析；需要改变计划安排时在计划详情创建修订草稿。

`POST /api/agent/tasks/{id}/followups` 接收 `{"question":"..." }`，返回 202 和新任务。前序任务必须属于当前登录者，状态为已完成，且仍符合现行数据授权。任务通过 `parentTaskId` 逻辑关联。

删除任务时，后续依赖该任务的追问会清除正文、统计和检查点，保留失效状态。源健康记录更正或删除时，追问沿用原任务数据范围和各模块现有的失效规则。

已有库在 027 及其他适用前序迁移后执行 `database/migrations/043_activity_followup.sql`。新库使用最新建表脚本。
