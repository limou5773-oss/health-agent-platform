# Agent 分析追问

对应 AG01。在已完成的睡眠分析或综合分析详情输入追问。系统为每轮生成独立任务，可查看进度、统计、反馈和前一轮入口。追问沿用前一轮的分析类型、日期、来源筛选及日记选项，并重新查询当前记录。Agent 只从前一轮引用问答作为背景。更换日期或来源需创建新任务。

`POST /api/agent/tasks/{id}/followups` 接收 `{"question":"..." }`，返回 202 和新任务。前序任务必须属于当前登录者，状态为已完成，且仍符合现行数据授权。任务通过 `parentTaskId` 逻辑关联。

删除任务时，后续依赖该任务的追问会清除正文、统计和检查点，保留失效状态。源健康记录更正或删除时，追问沿用原任务数据范围和各模块现有的失效规则。

已有数据库执行 `database/migrations/027_agent_followups.sql`。新库使用最新建表脚本。
