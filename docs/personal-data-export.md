# 个人数据导出

「个人档案 → 个人数据导出」下载 `personal-health-data.json`。也可用本人 JWT 请求 `GET /api/profile/export`。导出读取同一数据库快照，包含 `formatVersion`、`exportedAt` 和各模块的记录数组。持久化 JSON 字段保留结构。

包含账号基本信息、档案及授权设置、偏好、健康明细和日记、目标、Agent 任务及步骤摘要、计划及版本和打卡、报告、导入批次与拒绝分类、通知、主动任务和知识收藏。日期与时间沿用数据库字段的业务口径。没有记录的模块返回空数组。

密码哈希、任务令牌、原始上传文件、导入暂存行和模型检查点不在导出范围内。健康时间线仍支持按日期、类型和来源导出。此功能沿用已有表结构。
