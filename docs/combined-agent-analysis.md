# Agent 综合分析

在「健康助手」选择「综合分析」，填写目标和日期，按需指定睡眠来源。综合分析通过 JWT 创建任务，并沿用外部模型授权、任务进度、补充、重试和取消。已有库执行 `database/migrations/024_combined_agent_analysis.sql`。

Java 通过已有 Mapper 和统计服务按同一日期范围汇总睡眠、步数、运动、体重和心率。工具只使用任务保存的用户与日期。Agent 可选择 `get_combined_statistics` 获取结果，完成分析前必须取得有效统计。逐日表来自工具返回值，缺失保持为空。睡眠沿用来源选择，其余指标发生来源冲突时只标记该指标并排除其数值。模型仅比较实际观测日期重合的数据，需说明覆盖差异和单位。

任务详情提供各指标的来源和时间线入口。运动统计包含与周期重叠的时段，时间线入口显示在周期内开始的运动。日记沿用档案授权、任务勾选和逐条授权，工具最多返回最近 20 条。结果单独保留本次工具读取的日记编号供本人核对。同期指标变化和日记自述仅作为时间上的关联。

睡眠与授权日记继续使用既有清理流程。步数、运动、体重或心率的源记录更正、删除时，覆盖原记录日期的综合分析任务被标记失效，清除任务内容、执行步骤和检查点。任务编号与状态可用于追溯。
