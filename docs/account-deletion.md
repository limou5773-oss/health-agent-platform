# 删除账号和个人数据

普通用户在「个人档案 → 删除账号和个人数据」查看范围，输入当前密码并确认。成功后退出登录，旧 JWT 因账号不存在而失效。系统管理员通过启动配置管理，账号不提供自助删除。

接口为 `DELETE /api/profile/account`，请求体为 `{"password":"当前密码"}`，身份取自 JWT，成功返回 204。服务在账号行锁内复核密码，删除本人账号、档案、健康数据、偏好、消息、计划、报告、任务和导入数据。通过逻辑关联清理计划版本、打卡、导入暂存行及问题分类。共用知识资料、模板及系统配置保留。

Agent 检查点由 Python 清理。清理失败时数据库事务回滚，可以在服务恢复后再次确认。此前已经清理的检查点无法由数据库回滚恢复。已下载的副本及外部模型已接收的数据由各自持有者管理。

使用已有表结构，无新增迁移。
