# 综合健康看板

首页按同一日期范围显示睡眠、步数、运动、饮食、饮水、体重和心率。每项可独立选择数据来源。数据来源冲突时该项显示服务端提示，其他指标仍可查看。统计和每日图表使用各业务模块的接口及统计口径。

卡片显示指标单位、已应用日期范围、有效记录覆盖及逐日数值。睡眠、步数、饮食、饮水、体重和心率显示最新观测时间。步数按筛选后的区间结束时间显示数据截止，并显示已设置的每日目标及有效日达标数。缺失值在图表留空，记录值为零时保留标记。饮食热量图只汇总已知热量，并列出手动、估算和未知条目数。

无记录时可从卡片进入对应模块补录。心率显示采样均值、采样总数和覆盖天数。已有库执行 `database/migrations/022_heart_rate_samples.sql`。详见[心率采样](heart-rate.md)。

睡眠卡片展开逐日数值后显示最早入睡、最晚醒来及相邻有记录日期的平均时间变化。切换日期或来源后按当前筛选重新计算。计算口径见[睡眠接口契约](api-contract.md)。
