# 健康报告 PDF

对应 EX06。在「健康报告」选定报告版本，点击「导出 PDF」，再在浏览器打印窗口选择「另存为 PDF」。可关闭浏览器打印页眉和页脚。

点击「导出 PDF」会重新通过本人 JWT 请求选中报告。报告失效时刷新状态，不打开报告打印版。直接启动浏览器打印会提示使用导出按钮。打印标题包含报告编号、版本和周期，可作为浏览器保存 PDF 时的文件名。打印版包含所选报告正文、周期、来源、数值与单位、统计图及逐日数据或缺失日期。逐日表格按 A4 页面排版并在跨页时重复表头。浏览器使用系统中文字体排版。综合报告和专项报告用条形图表示覆盖，睡眠报告沿用已保存的每日睡眠趋势。

无需数据库迁移或额外的 PDF 服务。PDF 生成由浏览器完成。
